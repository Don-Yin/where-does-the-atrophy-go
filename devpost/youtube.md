## Title
Where Does the Atrophy Go? | A Brain-Warp Lesson in Lens Studio Preview

## Public description
Where Does the Atrophy Go? makes brain registration, the alignment of a scan to a reference, into a spatial lesson in Lens Studio Interactive Preview.

Follow a real public brain scan from its own coordinates into common reference space. Drag the moving brain along the curved table guide and watch the selected coral ventricle region travel with it. Blue warp colour shows stretching; red shows squeezing. Compare viewer-facing scan slices, select a paired slice for a closer look, or lift an inspection copy with a stationary hold and release it to return.

This is a mouse-driven Lens Studio Interactive Preview demonstration. The project was planned with plan-lens and built with CLAD, Snap's building-agent workflow, through Lens Studio's Model Context Protocol tools driven from the Pi coding agent. LEAF integration tests check the Preview interactions.
